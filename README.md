# Anything Goes Formatter Plugin

The Anything Goes Formatter plugin provides an alternative markup formatter for Jenkins.

## Usage

Install the plugin, then configure the global Markup Formatter setting in Jenkins according to your instance policy.

## Issue Tracking

Please use GitHub issues in this repository for bug reports and feature requests.
Link pull requests with GitHub issues using references like `#123` and `Fixes #123` when appropriate.

## Maintainer status

This plugin is currently maintained by a single active maintainer.
At this time, we are not looking to transfer ownership or plugin adoption.

Co-contributors are very welcome. If you want to help with fixes, tests,
documentation, or maintenance, please open a PR or start a discussion.
